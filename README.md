DAY 3 — GENAI TOOLS & AVIATION MANAGEMENT LAB
1. Four-Component Prompt Building

A good prompt has 4 main components:

Role → Who should the AI act as?
Context → What background/information is needed?
Format → How should the answer look?
Tone → How should it sound?

Structured prompts produce more specific, professional and useful outputs and reduce chances of invented information.

⭐ Remember:

Role + Context + Format + Tone = Better Prompt

2. Change One Component

Changing only the tone changes how the same information is communicated.

Example:

Formal: “Please check the official app for updates.”
Warm: “We understand this delay may be inconvenient. Please check the official app for updates.”
Key learning:

Same information ≠ same communication style.

Passenger-feedback summary	Conversational AI

Human review = Yes for all important aviation outputs.

⭐ Remember:

Task → Required Output → Right AI Tool → Human Review

4. Current Information & Source Check

AI-generated information about current aviation topics must be checked against the original/official source.

For example:

Delhi Airport passenger-experience initiative → Check official Delhi Airport source.

Verification checklist:
Does source open?
Is publisher identifiable?
Is the date/currentness clear?
Does the source actually support the claim?

Final status: VERIFIED only after source checking.
